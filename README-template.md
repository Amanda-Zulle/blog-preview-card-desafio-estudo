### Captura de tela

Aqui deve ser adicionada uma captura de tela da sua solução:

`./screenshot.jpg`

A maneira mais fácil de fazer isso é usar o Firefox para visualizar seu projeto, clicar com o botão direito na página e selecionar **"Fazer uma captura de tela"**.

Você pode escolher entre uma captura da página inteira ou uma área recortada, dependendo do tamanho da página. Se a página for muito longa, talvez seja melhor fazer um recorte.

Como alternativa, você pode utilizar uma ferramenta como o **FireShot**. O FireShot possui uma opção gratuita, então não é necessário comprá-lo.

Depois, recorte, otimize ou edite a imagem da maneira que quiser, adicione-a ao seu projeto e atualize o caminho do arquivo da imagem acima.
